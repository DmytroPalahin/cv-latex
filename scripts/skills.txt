# Skills that scripts/match_offer.py recognises in a job offer and in the CV.
#
# One skill per line: the name shown in the report, then its other spellings after "|"
# (other names, abbreviations, French wording).
#
# The matching already accepts, without a line of its own:
#   - any case: "python" finds Python (except names of 1 or 2 letters: Go, R, C, BI)
#   - missing accents: "qualite des donnees"
#   - a space, a hyphen, a slash or nothing between two words: PowerBI, data-lake, CI CD
#   - a final "s": LLMs, pipelines
#
# A term the report misses: add a line. A term found by mistake: remove its line.
